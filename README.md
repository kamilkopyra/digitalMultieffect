# Multieffect Daisy

STM32 (Daisy Seed) port of the [Multieffect](https://github.com/kamilkopyra/digitalMultieffect)
guitar multi-effect engine. Independent repo from the PC/Qt version — this is
where the embedded rewrite lives.

## Status

Main app (`src/main.cpp`): the screen GUI drives a 3-slot effect chain on real
hardware. All effects are ported except Delay (stub — its buffer still has to move
to SDRAM) and Tuner (needs a rewrite without threads; the tuner screen shows demo
data). See below.

## Dependencies (not committed, fetch separately)

Only [libDaisy](https://github.com/electro-smith/libDaisy) (hardware/system
library) is used — effects are our own, so DaisySP is not needed. It is vendor
code, intentionally left out of this repo. Fetch it into `daisy/libDaisy`:

```sh
git clone https://github.com/electro-smith/libDaisy.git daisy/libDaisy
```

Build it (needs `arm-none-eabi-gcc` and a `make`, e.g. `mingw32-make` on Windows):

```sh
cd daisy/libDaisy && mingw32-make -f Makefile MAKE=mingw32-make -j4
```

## Building the firmware

From the repo root (Git Bash), with the ARM toolchain on `PATH`:

```sh
mingw32-make MAKE=mingw32-make -j8
```

Output: `build/multieffect.bin` (program) and `build/multieffect_assets.bin`
(GUI art + fonts, kept in QSPI at `0x90400000` instead of SRAM — see
`ld/STM32H750IB_sram_assets.lds` and `UI_ASSET` in `ui/font.h`).

## Ported so far

`EffectChain` has 3 slots, like the GUI. The pool of effects is registered in
the GUI order (`ui.cpp` `kEffects`), so `Preset.effect[]` indices map directly:
Fuzz, Tremolo, NoiseGate, Rat, TubeScreamer, Delay (stub), Compressor, Vibrato,
Flanger, Phaser, AutoWah, Equalizer, Boost. One effect object can sit in only
one slot at a time. Effect parameters are recalculated only when they change
(`Effect::onParamChange()`), not per sample.

## Flashing

The app is `BOOT_SRAM`: the Daisy bootloader (internal flash) copies the program
from QSPI to SRAM on every start. Enter the bootloader: tap **RESET**, then press
**BOOT** within 2 s. Then:

```sh
mingw32-make program-assets   # art + fonts, only when they change
mingw32-make program-dfu      # program, after every code change
```

If the bootloader is gone (overwritten by a `BOOT_NONE` app such as
`tests/bypass`): hold **BOOT**, tap **RESET**, release, then
`mingw32-make program-boot`.

## Screen GUI (`ui/`)

GUI for the Waveshare 4" TFT Touch Shield (ILI9486 480x320 SPI, XPT2046 touch),
shared between the Daisy app and a PC simulator:

- `ui/` — screens (main, presets, tuner, settings, effect picker), drawing into a
  480x320 framebuffer with anti-aliasing; `platform.h` is what a platform provides
- `ui/assets/` — generated by `python ui/tools/gen_assets.py`: effect art from the
  Qt version (`qt-gui` branch, full colour 80x96) and fonts (Source Han Sans,
  SIL Open Font License 1.1, rendered to 4-bit alpha)
- `tests/ui_daisy/` — Daisy app: screen + touch over SPI1, presets in QSPI flash,
  audio passthrough with master volume, real input meter and CPU load
- `tests/ui_sim/` — PC simulator, `./build.sh` writes PNG screenshots and a PDF
  (needs `g++`, e.g. `C:/Qt/Tools/mingw1310_64/bin`, and Python with Pillow);
  current preview: `tests/ui_sim/preview/Multieffect_UI_Daisy.pdf`

Wiring (Daisy GPIO (Seed pin) -> shield Arduino header): D0 (1) -> D3 (TP_IRQ),
D1 (2) -> D4 (TP_CS), D2 (3) -> D5 (SD_CS), D3 (4) -> D7 (LCD_DC),
D4 (5) -> D8 (LCD_RST), D5 (6) -> D9 (LCD_BL), D7 (8) -> D10 (LCD_CS),
D8 (9) -> D13 (SCLK), D9 (10) -> D12 (MISO), D10 (11) -> D11 (MOSI), GND,
5-9 V to the shield's 5V pin. Shield's SPI Config switch on D11/D12/D13 (not ICSP).
The shield runs at 3.3 V internally, so nothing it sends back exceeds 3.3 V.

Encoders (CLK, DT, SW; internal pull-ups, module + to 3V3 only, never 5V):
E1 = D18, D19, D20 (Seed pins 25, 26, 27), E2 = D21, D24, D25 (pins 28, 31, 32),
E3 = D26, D27, D28 (pins 33, 34, 35). They are read in a 1 kHz timer interrupt,
so a slow screen redraw never loses steps.

| Screen | E1 | E2 | E3 |
|---|---|---|---|
| main (turn) | param 1 / master volume | param 2 | param 3 |
| main (push) | next effect (3 -> VOL -> 1) | effect on/off | menu (modulation: tap, hold = menu) |
| menu, picker, presets, settings | turn = select, push = OK / load | turn = value, push = save (presets) | push = back |

`tests/ui_daisy` is also `BOOT_SRAM` (art and fonts in SRAM, no separate
assets file): `./daisy/tools/dfu-util-0.9-win64/dfu-util.exe -a 0 -s 0x90040000:leave -D tests/ui_daisy/build/ui_daisy.bin -d ,0483:df11`.
